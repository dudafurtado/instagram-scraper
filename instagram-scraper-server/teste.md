Via DevTools (sem extensão)

O usuário abre o Instagram e pressiona F12 para abrir DevTools.

Vai até a aba Application → Cookies → https://www.instagram.com.

Copia manualmente os principais cookies: sessionid, ds_user_id, csrftoken, mid, etc.

Você pode pedir para colarem isso no seu front como um objeto JSON ou formulário.

✅ OPÇÃO 2 — Usar extensão como EditThisCookie
Essa é a forma mais completa e fácil para o usuário comum.

Passos:
Instale a extensão no Chrome.

Vá para instagram.com já logado.

Clique na extensão > ícone de exportar.

Ela gera um JSON com todos os cookies (inclusive os HttpOnly).
